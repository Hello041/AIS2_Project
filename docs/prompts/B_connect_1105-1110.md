### B1. UnivFD·NPR detector (김정효, 선행: A2·A4)

```
detectors/univfd.py, npr.py를 구현하자. 브랜치: feat/detectors-univfd-npr

1. base.Detector를 상속. load()에서 가중치를 inference/weights/에서 읽고, 없으면 README를 가리키는 명확한 오류.
2. 각 모델 공식 코드의 전처리(리사이즈·크롭·정규화)를 그대로 따른다. 공식 코드에서 어떤 부분을 가져왔는지 주석에 출처를 남겨.
3. 출력을 0~1, 클수록 AI 쪽으로 맞춰. 공식 출력이 logit이면 sigmoid, 방향이 반대면 뒤집고 그 이유를 주석에.
4. UnivFD는 CLIP 이미지 인코더만 로드.
5. inference/scripts/score_one.py <이미지> 로 활성 모델의 원점수 출력.
6. 확인: 실제 사진 2장, AI 이미지 2장으로 돌려서 결과 표를 보여줘. 방향이 직관과 반대로 나오면 원인을 조사해줘.
```

### B2. banding 단계 0 (임정민, 선행: A4)

```
inference/banding.py와 thresholds.yaml을 구현하자. 브랜치: feat/banding

2. banding.py:
   - load_thresholds(path)
   - band(model_name, score) -> 'weak'|'uncertain'|'strong' (경계값과 같으면 uncertain)

     ensemble.yaml 분기는 자리만 만들고 C3에서 채운다.
   - 모델 2개일 때 규칙 포함. 모델 1개 또는 0개면 어떻게 할지 내게 묻지 말고 uncertain으로 하고 주석에 남겨.
3. 테스트 inference/tests/test_banding.py (위치는 임시. CLAUDE.md 미결 사항 참고):
   - band 경계값(low, high 정확히 같은 값 포함)
   - 3모델: 모두 같음, 2:1 각 조합, strong+weak 공존, 셋 다 다름
   - 2모델: 같음, 다름
   - 규칙 3이 규칙 1에 포함된다는 점을 테스트 주석에 명시
4. pytest 실행 결과를 보여줘.
```

### B3. FastAPI 서버 (김정효·임정민, 선행: B1·B2)

```
inference/main.py에 /health, /analyze를 구현하자. 브랜치: feat/api

근거: 계획서 §5.4, 검토 문서 3·4번, CLAUDE.md 개인정보 규칙.

1. 시작 시(lifespan) DETECTORS의 모델을 모두 로드. /health는 로드된 모델 이름 목록 반환.
2. POST /analyze (multipart, 필드 image):
   - 10MB 초과 → 413. Content-Length 헤더로 먼저 거르고, 본문도 10MB+1바이트까지만 읽어 한 번 더 검사
     (FastAPI/uvicorn에는 기본 제한이 없음).
   - BytesIO로만 처리. Pillow로 열고 format이 JPEG/PNG/WEBP가 아니거나 디코딩 실패 → 400.
     디코딩 폭탄 대비로 Image.MAX_IMAGE_PIXELS를 확인.
   - 각 모델 score → band → overall. 추론 예외 → 500 (스택트레이스는 서버 로그에만, 이미지 정보 없이).
   - 응답은 §5.4 형식 그대로. provenance=null, elapsed_ms 포함.
3. 로깅: 요청마다 바이트 크기와 처리 시간만. 파일명·EXIF·이미지 내용 로그 금지.
4. 디스크 미저장 확인: 업로드 처리 중 tempfile/파일 쓰기가 없는지 코드 검토 결과를 보고하고,
   SpooledTemporaryFile을 쓰는 UploadFile 대신 bytes로 받는 방식을 썼는지 설명해줘.
5. CORS는 개발용으로 전체 허용하되 주석에 표시.
6. 테스트: DummyDetector로 200/400/413/500 각각 확인하는 pytest. 실제 모델로 curl 예시도 줘.
7. uvicorn은 --host 0.0.0.0. Windows 방화벽 8000 포트 여는 명령을 inference/README.md에 추가.
```
