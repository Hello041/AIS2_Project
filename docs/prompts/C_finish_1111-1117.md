### C2. fit_ensemble.py (김정효)

```
ml/fit_ensemble.py로 단계 1 앙상블을 학습하고 규칙 방식과 비교하자. 브랜치: feat/ensemble

근거: 계획서 §5.3 단계 1·채택 기준, 검토 문서 6번.

1. scores.csv를 읽어 GroupKFold(source_id, 5-fold). 각 fold에서 학습 부분으로만:
   모델별 Platt(a, b) → 보정 점수 3개로 LogisticRegression → τ 선택 → t_low, t_high 선택
   (t_high는 학습 부분 실제 사진 FPR ≤ 5%). 평가 부분에는 적용만.
2. 같은 fold로 규칙 방식(thresholds.yaml + banding.overall 규칙)도 평가.
   추가 비교: 모델별 단일, 단순 평균.
3. 비교표: 방식별 FPR, '강함/약함'으로 판정한 이미지의 정확도, '판단하기 어려움' 비율, fold별 편차.
   ml/reports/ensemble_compare.md로 저장.
4. 채택 기준(스태킹 FPR ≤ 규칙 FPR, 판정 정확도 ≥ 규칙) 충족 여부를 판정.
5. 전체 데이터로 다시 맞춘 최종 파라미터를 inference/ensemble.yaml로 저장(§5.3 형식, trained_on에 장수·날짜).
   채택 기준을 못 넘으면 파일은 ml/reports/에만 두고 inference/에는 넣지 마.
6. 데이터가 적어 생길 수 있는 문제(fold당 실제 사진 수, τ 선택의 불안정성)를 보고서 말미에 적어줘.
```

