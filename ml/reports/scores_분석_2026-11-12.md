# 검증 데이터 채점 결과 분석 (`ml/scores.csv`, 2026-11-12)

## 데이터

- 총 800장 = 실제 사진 400장 + AI 이미지 400장
- 실제: RAISE 풍경·자연 사진 원본 100장 + 변형 3종(jpeg70, resize50, screenshot) 각 100장
- AI: Cloudflare Workers AI 원본 100장(sdxl 34, sdxl-lightning 33, flux1-schnell 33) + 같은 변형 3종 각 100장
- 변형: jpeg70 = JPEG 품질 70 재압축, resize50 = 가로세로 50% 축소, screenshot = 긴 변 1080px 축소 후 PNG
- 모델: UnivFD, AIDE, B-Free. 원점수는 0~1, 클수록 AI 쪽 (확률 아님)
- 채점: `ml/score_samples.py` (서버와 같은 detector 코드), CPU i7-1165G7

AUC: AI 이미지 하나와 실제 사진 하나를 골랐을 때 AI 쪽 점수가 더 높을 확률. 1.0이면 완전 구분, 0.5면 무작위.
